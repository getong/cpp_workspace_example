# raft-rpc

This is the raft-rpc project: a replicated counter built on
[eBay/NuRaft](https://github.com/eBay/NuRaft). See
[docs/raft-nuraft-example.md](docs/raft-nuraft-example.md) for the design and
[docs/overlay-cluster.md](docs/overlay-cluster.md) for running a cluster across
NATs over a P2P overlay network (ZeroTier / Tailscale).
