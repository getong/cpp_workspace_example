# cobalt-example

This is the cobalt-example project: a demo of [boost::cobalt](https://www.boost.org/libs/cobalt)
(C++20 coroutines with CSP-style concurrency — channels, `race`/select) built on top of Boost.ASIO,
with dependencies managed by vcpkg.

See [docs/boost-cobalt.md](docs/boost-cobalt.md) for an explanation of the CSP
model, cobalt's components, and the examples in `source/main.cpp`.
